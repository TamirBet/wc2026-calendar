# לוח שנה מתעדכן – מונדיאל 2026 (משחקים נבחרים) ⚽

לוח שנה (פיד `.ics`) להרשמה מהטלפון, שמכיל את **המשחקים הבולטים** מתוך 104 משחקי
מונדיאל 2026 (ארה"ב / מקסיקו / קנדה, 11.6–19.7.2026):

- **כל משחקי הנוקאאוט** — שמינית 32, שמינית הגמר, רבע, חצי, מקום שלישי וגמר.
- **משחקי הבתים של נבחרות בולטות והמארחות** (ברזיל, ארגנטינה, צרפת, אנגליה, ספרד,
  גרמניה, פורטוגל, הולנד, בלגיה, קרואטיה, וכן ארה"ב, מקסיקו, קנדה).

בכל אירוע בהערות: **השלב**, **האצטדיון**, **מיקום האצטדיון**, ו**שעת המשחק בשעון ישראל**.

## למה זה מתעדכן לבד

הלוח נבנה מנתונים חופשיים של [openfootball/worldcup.json](https://github.com/openfootball/worldcup.json).
משחקי הנוקאאוט נשמרים עם מצייני־מקום ("מנצחת בית A", "מנצחת משחק 73") ומתמלאים
בשמות הנבחרות האמיתיות ככל שהטורניר מתקדם. GitHub Actions מריץ את הסקריפט
**פעמיים ביום** ומעדכן את `worldcup.ics` — והטלפון, שרשום ל־URL, מושך את העדכון לבד.

> כיוון שכל משחק שומר מזהה (`UID`) קבוע, עדכון שם נבחרת **מחליף** את האירוע הקיים
> במקום ליצור כפילות.

## התקנה חד-פעמית (פעם אחת)

1. צור חשבון GitHub (אם אין) וריפו חדש, והעלה אליו את הקבצים האלה.
2. ב-**Settings → Pages** הפעל Pages מענף `main` (תיקיית root).
3. ה־Action ירוץ אוטומטית (או הרץ ידנית מ-**Actions → Build → Run workflow**).
4. כתובת הלוח תהיה:
   `https://<שם-המשתמש>.github.io/<שם-הריפו>/worldcup.ics`

## הרשמה מהטלפון

**iPhone:** הגדרות → אפליקציות → לוח שנה → חשבונות → הוספת חשבון → אחר →
הוספת לוח שנה מנוי → הדבק את ה-URL.

**Android / Google Calendar:** במחשב בדפדפן ב-[calendar.google.com](https://calendar.google.com)
→ ליד "לוחות שנה אחרים" לחץ **+** → **מ-URL** → הדבק את ה-URL.
הלוח יסונכרן אוטומטית גם לאפליקציה בטלפון.

> Google ו-Apple מרעננים לוחות מנוי כל כמה שעות (לא מיידית), לכן צפוי עיכוב של
> עד כ-24 שעות בין סיום שלב הבתים להופעת שמות הנבחרות בנוקאאוט.

## הרצה מקומית / שינוי

```bash
node generate-ics.mjs   # יוצר worldcup.ics
```

- לשנות אילו נבחרות נכללות במשחקי הבתים: ערוך את `BIG_NATIONS` בראש `generate-ics.mjs`.
- לשנות תרגומים (שמות נבחרות / אצטדיונים / שלבים): ערוך את `translations.mjs`.

## קבצים

| קובץ | תפקיד |
|------|-------|
| `generate-ics.mjs` | מושך נתונים, מסנן, ומייצר את `worldcup.ics` |
| `translations.mjs` | מילוני עברית: נבחרות, אצטדיונים, שלבים |
| `.github/workflows/build.yml` | תזמון אוטומטי (פעמיים ביום) ב-GitHub Actions |
